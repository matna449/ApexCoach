ApexCoach — Privacy Policy

Last updated: 2026-07-31

ApexCoach is a personal training-coach application built and run by a single athlete for their own use. It is not a hosted service, and it is not offered to the public. This page exists because WHOOP's (and Strava's) OAuth application-registration process requires a published privacy policy URL for any app that requests access to a WHOOP or Strava account, including personal, non-commercial ones.

What data ApexCoach accesses

With your explicit authorization (OAuth 2.0), ApexCoach reads:

  • From WHOOP: recovery score, HRV, resting heart rate, cycle strain, and sleep data.
  • From Strava: recent activity data (type, distance, duration, heart rate, pace, elevation).

ApexCoach does not post, modify, or delete anything in your WHOOP or Strava account. It only reads data you've authorized it to read.

Where your data goes

All data ApexCoach retrieves is stored locally, in a single SQLite database file on the machine you run ApexCoach on. ApexCoach does not transmit your health or activity data to any server, third party, or cloud service. The only network calls it makes are directly to the WHOOP API, the Strava API, and a local, self-hosted Ollama instance running on the same machine for generating plain-language explanations of its recommendations — no data leaves your machine to reach a hosted AI service.

OAuth access and refresh tokens are encrypted at rest (Fernet symmetric encryption) before being stored in that same local database.

Who can see your data

Only the person running ApexCoach on their own machine. There is no multi-user access, no admin dashboard, and no analytics or telemetry collection.

Revoking access

You can revoke ApexCoach's access to your WHOOP or Strava account at any time from WHOOP's or Strava's own account settings (Apps/Connected Apps). Doing so invalidates the tokens ApexCoach has stored; ApexCoach will no longer be able to fetch new data until you reauthorize.

Contact

This is a personal project. Questions can be directed to the repository owner via GitHub.
